# Screenshots

This folder holds the app screenshots referenced from the main `README.md`.

Add the following images here after running the app on a device or emulator:

| File name | Screen |
|---|---|
| `dashboard.png` | Dashboard with balance, monthly summary and recent transactions |
| `add_transaction.png` | Add transaction form (income/expense, category, date) |
| `history.png` | Transaction history with search and category filter |
| `statistics.png` | Statistics screen with pie chart and monthly overview |
| `settings.png` | Settings screen with dark mode and currency selection |

Recommended capture size: a standard phone resolution (1080x2340 or similar),
PNG format, light theme.
